## Observations

Reporting the superstructure areas and stakeout points data obtained from the cross-sections of the road design and tabulating these reports on the cross-sections after the calculations, is a time-consuming task. The widely used codes in this area produce a single type of final product and use MS Access as a database. Designers who use these common codes and methods go through several steps before reaching Excel, the fundamental tool of civil engineering. While transferring superstructure areas to cross-sections as drawings, multiple stages are involved, and data is copied into many files, resulting in solutions with non-customizable format. These products cannot serve international projects.

## Achievements

- With Section Wizard, the user manages earthwork and superstructure data in customizable formats without the need for any intermediary software.
- The Section Wizard, working as a dual set (one in Excel and the other in MicroStation), writes the XML reports obtained from the cross-sections into Excel in columns defined by the user.
- Using this data, the user completes the earthwork calculations and addresses the columns to be processed and their positions in the cells on the cross-sections. The Section Wizard transfers the addressed Excel columns to the cross-sections.

## Key Features

- Easily filter End–Area Volume reports and transfer the required data to the desired columns in Excel.
- Write the desired Excel column information into a specific dgn-cell. The Excel-drawing connection is so easy that it is also suitable for projects in different formats, and it was initially developed for this purpose.
- Works in connection with Inroads and retrieves the cross-section sets this way. Fast results are obtained for multiple cross-section drawings.
- The option to draw titles for the provided information as cells in the cross-sections is also available. This feature was added to offer drawings in different languages for international projects. For example, a two-line header can be written in English and the local language in the dgn-cell, and the Section Wizard will uses this cell in the cross-sections. A similar two-line application cannot be done with any code or Inroads in a single operation.

## Developer Notes

It was developed for a superstructure renewal project at an intersection in Tashkent, Uzbekistan, based on the project requirements. It has not been used in KGM projects yet, but there is no obstacle to its use.  
Earthwork calculations for bench-excavation at fill work are still performed using the widely used methods. The inclusion of this item in the Section Wizard is planned in near future.
